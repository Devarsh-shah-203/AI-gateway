# AI Gateway — Working Memory

This directory is the current working memory for developing the browser-based AI Gateway.

The memory is intentionally human-readable Markdown.

- `plan.md` — what we will try next.
- `progress.md` — what has happened and what is complete/incomplete.
- `discoveries.md` — what we learned and why the current approach works.
- `closed-ideas.md` — approaches not to repeat without a strong reason.
- `cookbooks.md` — reusable recipes that worked.

The long-term product may evolve this into a more structured project-memory system.
